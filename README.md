# 🌱 Plant Disease Detection using CNN

A deep learning project that detects **plant diseases from leaf images** using a Convolutional Neural Network (CNN).

### ✨ Features

* Uses **PlantVillage Dataset**
* Classifies **38 plant disease classes**
* Built with **PyTorch**
* Image preprocessing and data augmentation
* CNN vs. baseline model comparison
* Confusion matrix and accuracy evaluation
* Achieved approximately **95% test accuracy**

### 🛠️ Tech Stack

`Python` `PyTorch` `Torchvision` `NumPy` `Matplotlib` `Scikit-learn`

### 📊 Model

The CNN uses **3 convolutional layers**, ReLU activation, max pooling, dropout, and fully connected layers for classification.
